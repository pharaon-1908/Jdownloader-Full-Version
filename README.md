## ⚡ Key Features
<a id="key-features"></a>

### Core Functionality:
- **Multi-host Compatibility** — Download from services like Mega, Dropbox, and Google Drive without limitations.
- **Link Capturer** — Automatically captures links copied to your clipboard for hassle-free downloads.
- **Download Control** — Start, stop, or pause downloads at your convenience.
- **Bandwidth Management** — Set preset bandwidth limits for smoother downloading.
- **Automatic Extraction** — Automatically extract compressed files as they download.

### Advanced Features:

- **Captcha Bypass** — Download files without manually inputting captchas.
- **Container File Support** — Import DLC, CCF, or RSFD container files for organized downloads.
- **Premium Account Integration** — Easily manage downloads using your premium accounts for faster access.
